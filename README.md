Student Buddy

📱 Student Buddy — A Smart Student Productivity App

Student Buddy is an Android application designed to help students manage their everyday academic activities in one place.

✨ Features

- 👤 Student Profile
- 📊 Attendance Tracking
- 📅 Timetable Management
- 📝 Assignments
- 🎓 Academic Records
- 💰 Expense Tracking
- 💡 Suggestions
- 🐞 Bug Reporting
- 🖼️ Profile Photo Management

🛠️ Built With

- Kotlin
- Jetpack Compose
- Android Studio
